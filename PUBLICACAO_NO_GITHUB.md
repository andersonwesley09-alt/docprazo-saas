# DocPrazo V3.1 — Repositório do sistema completo

Este pacote mantém o código-fonte original V3.1, sem banco, backups, anexos reais nem segredos.

**Recomendação: criar um repositório PRIVADO no GitHub.** O GitHub Pages não executa o servidor Node.js nem o banco SQLite. Para disponibilizar a demonstração no portfólio, use o pacote público separado `DocPrazo_GitHub_Pages_DEMO.zip`.

## Publicação do código
1. No GitHub, crie um repositório `docprazo-saas` e selecione Private.
2. Use Add file > Upload files e envie o conteúdo da pasta deste ZIP (não o ZIP em si).
3. Não envie sua pasta `data`, seu `.env`, chave do Resend, bancos reais nem backups.
4. Para execução local, extraia em uma nova pasta e use `npm start` com Node >=22.13.
5. Se já possui dados na V3.1, mantenha-os apenas em seu computador ou servidor privado.

A separação de código privado e demo pública protege a futura comercialização.
